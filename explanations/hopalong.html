Barry Martin's Hopalong

Hopalong Attractor

What is a Hopalong Attractor?

The Hopalong attractor is an orbital fractal popularized by Barry Martin. It is generated by a very simple set of equations that produce surprisingly complex and diverse geometric patterns, ranging from cosmic-like nebulae to symmetric star-like structures.

xn+1 = yn - sign(xn) · √(abs(b · xn - c))
yn+1 = a - xn

How is it rendered?

Similar to the Clifford attractor, the Hopalong is rendered through thousands of iterations of its defining equations. Starting from a point (usually 0,0), each iteration "hops" to a new location. By plotting these thousands of points, a global structure emerges that reveals the underlying mathematical beauty of the system.

A Galaxy of Parameters

The system is controlled by three parameters (a, b, and c). While the formula remains the same, different combinations of these values can create entirely different visual worlds. Some parameters result in dense, cloud-like clusters, while others create sharp, crystalline symmetries.
