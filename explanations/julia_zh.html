曼德博的内部视角

朱利亚集合

什么是朱利亚集合？

朱利亚集合（Julia set）是由法国数学家加斯顿·朱利亚（Gaston Julia）提出的一类复平面上的分形集合。它与曼德博集合密切相关：曼德博集合是通过改变 c 并固定初始点 z = 0 生成的；而朱利亚集合则是固定 c 值，通过改变初始点 z 来生成的。

zn+1 = zn2 + c

曼德博的孪生兄弟

两者之间存在深刻的联系：复平面上的每一个点 c 都对应一个独特的朱利亚集合。如果 c 位于曼德博集合内部，对应的朱利亚集合是连通的；如果 c 位于外部，朱利亚集合则是完全不连通的“康托尔尘埃”。

无限的复杂性

朱利亚集合展现出极其丰富的形态。有些像优雅的螺旋，有些像冰晶枝脉，有些则像蓬松的云团。与所有分形一样，它们在任何尺度下都包含着无限的细节和自相似性。
