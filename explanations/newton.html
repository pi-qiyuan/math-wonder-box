Root Finding Iteration

Newton Fractal

What is a Newton Fractal?

A Newton fractal is a boundary set in the complex plane characterized by Newton's method applied to a fixed polynomial p(z).

zn+1 = zn - f(zn) / f'(zn)

How is it rendered?

Newton's method is used to find the roots of an equation. In this fractal, we start at a point z in the complex plane and see which root it converges to. Each root is assigned a unique color.

Complexity from Simplicity

While the iteration rule is simple, the boundaries between the regions of convergence to different roots are incredibly complex and fractal. These boundaries are where the method is "undecided" about which root to go to.
