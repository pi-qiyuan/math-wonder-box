What is the Mandelbrot Set?

The Mandelbrot set is the set of complex numbers c for which the function f(z) = z² + c does not diverge when iterated from z = 0.

zn+1 = zn2 + c

How is it rendered?

For each pixel on your screen, we map it to a complex number c. We then repeat the calculation above. If the value stays small after many repetitions, the point is inside the set (usually colored black). If it grows to infinity, we color it based on how quickly it escaped.

Infinite Detail

The most amazing property of the Mandelbrot set is its self-similarity. No matter how deep you zoom into the boundary, you will find infinitely complex and beautiful patterns, often containing miniature copies of the entire set itself.
