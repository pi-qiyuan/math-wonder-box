Julia Set

What is a Julia Set?

The Julia set is a set of points on the complex plane that form a fractal. It is named after the French mathematician Gaston Julia. While the Mandelbrot set is generated by varying c and starting at z = 0, a Julia set is generated by fixing c and varying the starting point z.

zn+1 = zn2 + c

Mandelbrot's Twin

There is a deep connection between the two: every point c in the complex plane defines a unique Julia set. If c is inside the Mandelbrot set, its corresponding Julia set is connected. If c is outside, the Julia set is a "Cantor dust" of disconnected points.

Infinite Complexity

Julia sets exhibit incredible variety. Some look like elegant spirals, others like icy dendrites or fluffy clouds. Like all fractals, they contain infinite detail and self-similarity at every scale.
