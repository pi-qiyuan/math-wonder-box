自相似分形

列维 C 曲线 (Lévy C Curve)

什么是列维 C 曲线？

列维 C 曲线是一种自相似分形曲线，最早由欧内斯特·切萨罗描述，随后由保罗·列维对其进行了深入分析。它是“迭代函数系统”分形家族中的著名成员，以其如羽毛般轻盈、如织物般细腻的外观而闻名。

生成原理

从一条直线段开始。在每一步迭代中，将该线段替换为两条长度相等且成 90 度角的线段，这两条新线段与原线段共同构成一个等腰直角三角形（原线段为斜边）。重复这一过程，曲线会不断折叠，形成独特的“C”字形结构。

数学特性

  • 分形维数： 列维 C 曲线的豪斯多夫维数为 2。这意味着随着迭代次数趋于无穷，它最终会填满二维平面上的一个特定区域。
  • 边界： 该曲线的边界本身也是一个极其复杂的分形，其复杂程度堪比科赫雪花。
  • 对称性： 它在递归步骤中蕴含着内在的 45 度旋转对称性，这使得最终的图案呈现出一种平衡且交织的质感。

逻辑中的艺术

列维 C 曲线因其“织物感”而备受生成艺术家喜爱。它展示了如何通过一个极其简单的几何规则（将直线折叠成直角），创造出看起来像是有机蕾丝或精密数学挂毯的宏伟结构。
