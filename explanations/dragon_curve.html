Self-Similar Fractals

Dragon Curve (Heighway Dragon)

What is a Dragon Curve?

The Dragon Curve is a self-similar fractal curve that was first investigated by NASA physicists John Heighway, Bruce Banks, and William Harter. It is most easily understood through a simple paper-folding exercise: if you take a strip of paper and fold it in half repeatedly in the same direction, then open it so each fold is a 90-degree angle, you will see the Dragon Curve emerge.

The Folding Algorithm

The curve is generated by starting with a single segment. In each step, you replace each segment with two segments at a right angle, alternating the direction of the turn (left or right). Mathematically, this can be represented as an L-system or an iterative sequence of turns.

Mathematical Properties

The Dragon Curve has several fascinating properties:

  • Space-Filling: As the number of iterations approaches infinity, the curve fills a specific area of the plane.
  • Non-Self-Crossing: Although it becomes incredibly dense, the path never crosses itself in a way that creates a closed loop.
  • Tiling: Multiple dragon curves can tile the plane perfectly without any gaps or overlaps.

Complexity from Simplicity

Like many fractals, the Dragon Curve demonstrates how a very simple rule applied recursively can create a pattern of immense beauty and structural complexity.
