相泽吸引子

球状奇异吸引子

它是什么？

相泽吸引子是一个生成具有优美且复杂结构的奇异吸引子的数学系统。它由数学家 Langford 发现，后来以普及该研究的 Aizawa 命名。

与蝴蝶状的洛伦兹吸引子不同，相泽吸引子形成一个大体呈球形的壳体，中心中空，并带有一个沿 Z 轴延伸的独特“柄”或“尾部”。它代表了一个保持在特定几何形状内的混沌系统。

数学方程

该系统由以下三个微分方程定义：

dx/dt = (z - b)x - dy
dy/dt = dx + (z - b)y
dz/dt = c + az - z³/3 - (x² + y²)(1 + ez) + fzx³

常用参数：a = 0.95, b = 0.7, c = 0.6, d = 3.5, e = 0.25, f = 0.1。

混沌的几何学

相泽吸引子的特点是在 X 和 Y 维度上几乎完全对称。点绕 Z 轴轨道运动，同时上下振荡。项 (x² + y²)(1 + ez) 起到了阻尼力的作用，使轨迹保持在球形表面附近，而其他项则提供了混沌能量，防止路径重复。

可视化吸引力

在本次可视化中，我们通常将三维轨迹投影到 X-Z 平面（侧视图）或 X-Y 平面（俯视图）。侧视图展示了独特的类心形或球形轮廓及其垂直对称轴，而俯视图则展示了围绕中心的螺旋轨道。
